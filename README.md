# WillwitcherOS

This repository contains the complete NixOS configuration for a desktop system, managed with Nix Flakes, Home Manager, and `stylix`. It's a highly customized setup with a focus on a visually appealing and functional desktop experience.

## Installation

This configuration is meant to be installed on a new machine from a NixOS live ISO.

**1. Boot from a NixOS live ISO.**

**2. Connect to the internet.**

**3. Partition the disk.**

You can use `gparted` or `fdisk` to partition your disk. You'll need at least two partitions:

*   A boot partition (at least 512MB, FAT32, with the `boot` flag).
*   A root partition (the rest of the disk, ext4).

**4. Mount the partitions.**

Mount the root partition to `/mnt` and the boot partition to `/mnt/boot`.

```bash
mount /dev/sdX2 /mnt
mkdir /mnt/boot
mount /dev/sdX1 /mnt/boot
```

**5. Generate the NixOS configuration.**

```bash
nixos-generate-config --root /mnt
```

**6. Clone this repository.**

```bash
nix-shell -p git
git clone https://github.com/willwitcher/willwitcher-OS-Endgame /mnt/etc/nixos
```

**7. Edit the `hardware-configuration.nix` file.**

Copy the `fileSystems` and `swapDevices` from the generated `hardware-configuration.nix` to `hosts/desktop/hardware-configuration.nix`.

**8. Install NixOS.**

If you don't have flakes enabled in your Nix configuration, you can run `nixos-install` with the following command:

```bash
nixos-install --extra-experimental-features "nix-command flakes" --flake /mnt/etc/nixos#desktop
```

If you have flakes enabled, you can simply run:

```bash
nixos-install --flake /mnt/etc/nixos#desktop
```

**9. Reboot.**

## Direct Flake Installation

Alternatively, you can install the flake directly from the live ISO without cloning the repository. This is useful for a quicker installation.

**1. Follow steps 1-5 from the regular installation.**

**2. Install NixOS directly from the flake.**

If you don't have flakes enabled in your Nix configuration, you can run `nixos-install` with the following command:

```bash
nixos-install --extra-experimental-features "nix-command flakes" --flake github:willwitcher/willwitcher-OS-Endgame#desktop
```

If you have flakes enabled, you can simply run:

```bash
nixos-install --flake github:willwitcher/willwitcher-OS-Endgame#desktop
```

This will automatically fetch the flake and install the `desktop` configuration. You will need to edit the `hardware-configuration.nix` after the first boot and rebuild the system.

**3. Reboot.**

## Repository Structure

*   `flake.nix`: The entry point for the NixOS configuration. It defines the inputs (nixpkgs, home-manager, stylix) and the output (the NixOS configuration).
*   `hosts/desktop/`: This directory contains the configuration for the `desktop` host.
    *   `configuration.nix`: The main NixOS configuration file. It imports `hardware-configuration.nix` and `stylix`, and configures the system's boot loader, network, users, and services.
    *   `home.nix`: The Home Manager configuration file. It installs user-level packages, manages dotfiles, and configures user-level services.
    *   `hardware-configuration.nix`: This file is generated by `nixos-generate-config` and contains the hardware-specific configuration for the system.
*   `scripts/`: This directory contains a collection of shell scripts for various tasks.
*   `themes/`: This directory contains a collection of `stylix` themes.
*   `wallpapers/`: This directory contains a collection of wallpapers.

## Scripts

*   `ww-audio-toggle`: Toggles mute/unmute for the default audio sink.
*   `ww-bluetooth-status`: A script for `waybar` that shows the bluetooth status.
*   `ww-bluetooth-toggle`: Toggles bluetooth on/off.
*   `ww-power`: A script for gracefully shutting down, rebooting, or logging out. It ensures that Steam is closed properly before proceeding.
*   `ww-rec-rofi-region`: A `rofi` script for recording a region of the screen with `gpu-screen-recorder`.
*   `ww-rec-rofi-screen`: A `rofi` script for recording the entire screen with `gpu-screen-recorder`.
*   `ww-rec-stop`: Stops a `gpu-screen-recorder` recording.
*   `ww-screenrec`: A wrapper script for `gpu-screen-recorder` that provides a more user-friendly interface.
*   `ww-screenrec-status`: A `waybar` script that shows the screen recording status.
*   `ww-wallpaper-apply`: Applies the wallpaper selected by `ww-wallpaper-picker`.
*   `ww-wallpaper-picker`: A `rofi` script for picking a wallpaper.
*   `ww-wifi-status`: A `waybar` script that shows the wifi status.
*   `ww-wifi-toggle`: Toggles wifi on/off.

## Theming

The system is themed using `stylix`. The configuration is in `hosts/desktop/configuration.nix`. The base16 scheme is `catppuccin-mocha`, and the wallpaper is `wallpapers/images/cat.png`.

## Wallpapers

The `wallpapers` directory contains both static images and live wallpapers (videos). The `ww-wallpaper-picker` script allows you to choose a wallpaper, and the `ww-wallpaper-apply` script applies it.

To add a new wallpaper, simply copy it to the `wallpapers/images` or `wallpapers/live` directory.
